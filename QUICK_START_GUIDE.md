# Kids Puzzle Game - Quick Start Guide

## 🎮 How to Play

### For Teachers/Parents (Game Host):

1. **Start the Game**
   - Click "CREATE ROOM (START GAME)"
   - Enter your name
   - Choose a theme:
     - 🎒 School Day (classroom adventures)
     - 🐶 Pet Rescue (helping animals)
     - 🏴‍☠️ Treasure Hunt (finding treasures)
     - 🦸 Superhero Mission (being a hero)
   - Select difficulty: Easy / Medium / Hard
   - Set number of puzzles (1, 3, or 5)
   - Set time per puzzle (1, 2, or 3 minutes)

2. **Share Room Code**
   - You'll see a big ROOM CODE on screen
   - Share this code with students/kids
   - Watch as they join in real-time

3. **Start When Ready**
   - Wait for at least 1 player to join
   - Click "START GAME NOW"
   - Game begins with 3-second countdown

4. **During Game**
   - You can play along with kids
   - See live leaderboard
   - Click "EXIT" button anytime to leave

### For Kids (Players):

1. **Join the Game**
   - Click "JOIN ROOM (PLAY WITH FRIENDS)"
   - Enter the ROOM CODE (get from teacher/parent)
   - Enter your name
   - Click "JOIN ROOM"

2. **Wait for Start**
   - You'll see other friends joining
   - Wait for host to start the game
   - Click "LEAVE ROOM" if you change your mind

3. **Play the Game**
   - Read what the friendly character says
   - Type questions or answers in the chat box
   - Try to find clues and solve the puzzle
   - Watch the timer - solve it fast for more points!
   - See your rank on the leaderboard

4. **Have Fun!**
   - Complete all puzzles to win
   - See who got the highest score
   - Click "PLAY AGAIN" to start a new game

## 🎯 Tips for Success

### For Kids:
1. **Read Carefully** - The character gives hints
2. **Ask Questions** - Don't be afraid to ask anything
3. **Look for Clues** - Each clue helps you solve it
4. **Work Fast** - More time left = More points
5. **Have Fun** - It's okay if you don't solve it right away!

### For Teachers/Parents:
1. **Start with Easy** - Let kids get comfortable first
2. **Use 3 Puzzles** - Good balance, not too long
3. **Give 2 Minutes** - Enough time to think
4. **School Day Theme** - Most relatable for classroom
5. **Encourage Reading** - Kids must read to understand

## 🔧 Troubleshooting

### "Can't see other players"
- Refresh the page
- Make sure everyone joined the same ROOM CODE
- Check internet connection

### "Leaderboard not updating"
- It updates automatically, wait a few seconds
- Try submitting an answer to refresh

### "Want to leave game"
- Click "EXIT" button (top right during game)
- Click "LEAVE ROOM" (in lobby)
- You can always start a new game

### "Timer ran out"
- Don't worry! Game moves to next puzzle automatically
- You still get some points
- Try to be faster next time
